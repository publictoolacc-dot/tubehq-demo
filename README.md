# TubeHQ 체험판

다채널 운영 대시보드 TubeHQ의 체험판입니다. 화면의 채널과 수치는 모두 예시 데이터이며, 입력한 내용은 보는 사람의 브라우저에만 저장됩니다.

체험 주소: https://publictoolacc-dot.github.io/tubehq-demo/

## 체험 순서

1. 대시보드에서 7개 채널의 수익·비용·순이익을 비교합니다.
2. 비용 메뉴에서 채널별 지출을 확인하거나 예시 비용을 입력합니다.
3. 유튜브 도구에서 아웃라이어 탐색, 제목·후킹 문구 분석, 경쟁 채널 비교, CSV 내보내기를 사용합니다.

예시 실적은 2026년 1월 1일~8월 25일입니다. 기본 화면은 자료가 있는 2026년 8월로 열립니다.
미집계 날짜는 추이에서 제외하고, 부분 기간은 전월/전년의 같은 날짜 범위와 비교합니다.
비용 구성에는 직접 기록한 비용과 영상 편집 외주비가 포함되며, 인센티브는 별도로 집계합니다.
채널별 순이익은 배정된 비용만 차감하고, 전체 순이익에는 공통비용도 포함합니다.

## 유튜브 도구의 체험 범위

- 예시 채널: `@alsscut`, `@moneyclips`, `@reviewroom`
- 가상 영상의 제목·조회수·날짜를 원래 도구의 분석 로직에 넣어 실행합니다.
- CSV/TXT 다운로드는 실제로 동작합니다. 예시 영상의 실제 재생이나 실시간 유튜브 조회는 제공하지 않습니다.
- 썸네일 일괄 다운로드·썸네일 비교 보드 저장·댓글 답글 관리는 실제 제품의 계정/서버 연동 기능이므로 소개만 제공합니다.

## 공개 데이터와 저장

계정 연결 및 외부 발행 기능은 공개 체험판의 화면에서 제외했습니다.
실제 운영 데이터나 인증 정보는 포함하지 않습니다. 체험 입력은 브라우저 로컬 저장소에만 보관됩니다.
이전 체험판과 저장 영역을 분리했습니다. 설정에서 예시 데이터로 초기화할 수 있습니다.

## 이번 수정의 확인 사항

- TypeScript 검사 및 단일 HTML 빌드 통과
- 8월 미집계 날짜 제외 및 전월 1~25일 비교 확인
- 채널 필터에 따른 비용 차트·직접 기록 합계 확인
- 비용 입력 후 새로고침 시 유지 확인
- 4개 유튜브 도구의 분석 실행 및 24행 CSV 다운로드 확인

이 저장소에는 공개용 실행 HTML만 배포합니다. 실제 서비스와 계정 데이터는 별도로 관리합니다.
